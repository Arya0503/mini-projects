# Task :- JavaScript - Even or Odd Checker

## Project Overview
I wrote a JavaScript program to determine if a given number is even or odd using `if-else` statements. 

## How to Run
1. Unzip the downloaded folder.
2. Open `index.html` in your web browser.
3. Open the Developer Tools (Right-click -> Inspect, or press F12).
4. Navigate to the "Console" tab to view the output statements.
