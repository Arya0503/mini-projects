# Task: Tailwind Hero Landing Page

## Project Overview
This project is a modern digital workspace hero landing page built entirely with Tailwind CSS. The primary goal was to implement advanced CSS positioning techniques (`relative`, `absolute`, `sticky`, and `fixed`) using Tailwind's utility classes without writing any custom CSS.

## How to Run
1. Unzip the project folder.
2. Open `index.html` in your web browser. 
*(No build tools or command-line installations are required as this utilizes the Tailwind Play CDN).*

## Personal Reflection
Transitioning to Tailwind CSS was an interesting experience. At first, seeing so many classes in the HTML felt cluttered, but I quickly realized how much faster it is to build layouts when you don't have to constantly switch between an HTML file and a CSS stylesheet.
