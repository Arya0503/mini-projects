# Task : JavaScript - Loops

## Project Overview
This task is a JavaScript program designed to perform multiple mathematical operations on a given number, including checking for primes, generating multiplication tables, and identifying Armstrong numbers. 

## How to Run
1. Unzip the project folder.
2. Open `index.html` in your web browser.
3. Open the Developer Tools (Right-click -> Inspect, or press F12).
4. Click on the "Console" tab to view the analysis of the 5 test variables.
