# Task: JavaScript - Promise-based Divide Function

## How to Run
1. Unzip the project folder.
2. Open `index.html` in your web browser.
3. Open the Developer Tools (Right-click -> Inspect, or press F12).
4. Click on the "Console" tab to view the 5 test cases.

## Personal Reflection
This task was a really interesting shift in how I think about error handling. Normally, I would handle a division-by-zero error using a standard `try-catch` block or a simple `if-else` return statement. Wrapping the math in a JavaScript Promise forced me to think asynchronously.
