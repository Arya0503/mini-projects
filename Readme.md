# Task: CSS - Laundry Services Responsive Issue

## Project Overview
This task involved taking a previously built desktop-only layout for the Laundry Services app and using CSS Media Queries to make it fully responsive across tablet and mobile device widths.

## How to Run
1. Unzip the project folder.
2. Open `index.html` in your web browser. 
3. **To Test Responsiveness:** Right-click the page, select "Inspect", and either manually drag the browser window smaller or use the Device Toolbar to toggle between Desktop, Tablet (e.g., iPad Mini), and Mobile (e.g., iPhone SE) views.

## Personal Reflection
This assignment really helped me grasp the "mobile-first" versus "desktop-first" styling approach. I started by setting up the base CSS for the wide desktop view. Converting the navbar from `display: inline` to `display: flex` made a huge difference in how cleanly the items spaced themselves out using `justify-content: space-between`.
