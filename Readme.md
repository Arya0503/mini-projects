# Task 20: Laundry Services Web App (Final Project)

## Project Overview
This project is a fully functional, responsive single-page web application for a Laundry Service. It features dynamic DOM manipulation for cart management, smooth scrolling, and live third-party API integration via EmailJS to send automated confirmation emails to users upon booking.

## How to Run
1. Unzip the project folder.
2. Open `index.html` in your browser.
3. Test the "Book a service today!" button to watch the smooth scroll effect.
4. Add items to your cart, fill out the booking form with a valid email address, and click "Book now" to trigger the success message and test the EmailJS integration.
