# Task : OmniFood Responsive Landing Page

## Project Overview
This project is a fully responsive, single-page landing website for a fictional food delivery brand called OmniFood. The goal was to translate a static design into a functional webpage while ensuring it looks great on desktops, tablets, and mobile devices without relying on CSS frameworks.

## How to Run
Simply download the project folder, ensure the `assets` folder is in the same directory as the code, and open `index.html` in any web browser.

## Personal Reflection
Tackling this full landing page was a massive step up in layout architecture. After working with JavaScript and DOM manipulation recently, stepping back into pure HTML and CSS forced me to really think about how elements flow naturally down a page.
