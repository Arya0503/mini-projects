# Task: CSS - Laundry Services Button Interactive (Transforms)

## Project Overview
For this task, I was instructed to add a dynamic hover effect to the Call To Action (CTA) button in our Laundry Services hero section. The goal was to make the button increase in size and tilt slightly when the user hovers their mouse over it.

## How to Run
1. Unzip the project folder.
2. Open `index.html` in your web browser. 
3. Hover your mouse over the blue "Book a service today!" button to see the animation in effect.

## Personal Reflection
This was a short but really satisfying task! I previously knew how to use the `:hover` state to change basic properties like `background-color`, but physical manipulation using `transform` is entirely new to me.
