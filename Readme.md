# Task: CSS - Laundry Mart Login Page (Flexbox)

## Project Overview
This task is a responsive, split-layout login page for Laundry Mart. The primary objective was to rely entirely on CSS Flexbox for both the macro-layout (centering the main container on the screen) and the micro-layout (aligning the form elements and the split sections side-by-side).

## How to Run
1. Unzip the project folder.
2. Ensure `index.html` and `index.css` are in the same directory.
3. Open `index.html` in your web browser. 

## Personal Reflection
This assignment really solidified why Flexbox is so powerful compared to older layout methods. The instruction to explicitly *not* use margin or padding to center the main box pushed me to apply flex properties directly to the `body` tag. By setting the body to `height: 100vh`, `display: flex`, `justify-content: center`, and `align-items: center`, the login card locked perfectly into the dead-center of the screen.
