# Task: CSS Mini Project - Thala 7 Sneaker Store (Single-Page Layout)

## Project Overview
This project is a complete e-commerce flow for the "Thala 7 Sneaker Store." Instead of splitting the project across multiple HTML files, I architected this as a unified Single Page Application (SPA) layout. All views—the Landing Page, Product Display Page, Shopping Cart, and Checkout—exist within a single HTML document separated by `<section>` tags. 

## How to Run
1. Unzip the project folder.
2. Open `index.html` in your web browser.
3. Scroll down the page to view the sequential flow from Landing to Checkout, or click the links in the fixed top Navbar to instantly jump to specific sections.

## Personal Reflection
Consolidating this multi-page design into a single file was a highly practical exercise. When shopping for lightweight, durable football shoes for a slim fit, I usually prefer interfaces that don't force a hard page reload for every step of the checkout process. Building this layout into a continuous scroll mirrored that modern, fluid user experience.
