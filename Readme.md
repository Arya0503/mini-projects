# Task: CSS - Laundry Services Image Animation

## Project Overview
This task required taking the Hero Section image and adding a continuous CSS animation. The instructions specified two requirements: the image needed to move in an orbital rotation, and it needed to squeeze/distort at certain points in the orbit to make it visually interesting.

## How to Run
1. Unzip the project folder.
2. Open `index.html` in your web browser. 
3. Watch the laundry machine image continuously float in a circular pattern while gently squishing and stretching.

## Personal Reflection
Moving from `:hover` transitions to `@keyframes` was a really fun jump in logic. A hover transition is just an "A to B" change, but keyframes let you plot out an entire journey.
