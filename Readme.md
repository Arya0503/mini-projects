# Task: DOM Manipulation and Interactive Elements

## How to Run
1. Unzip the project folder.
2. Open `index.html` in your web browser.
3. Click on the color boxes to see them fill with their respective colors.
4. Type your name in the input box and click "Greet" to see the header update dynamically.

## Personal Reflection
This task was a great introduction to working directly with the DOM. Instead of just logging data to the console, I finally got to make the webpage visually react to user input.
