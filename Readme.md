# Task: JavaScript - Arrays and Functions

## Overview
This project contains solutions for analyzing array elements in JavaScript using different function paradigms 

## How to Run
1. Clone or extract the project files into a single folder.
2. Open `index.html` in any modern web browser.
3. Open Developer Tools using `F12` (or Right-Click -> Inspect) and select the **Console** tab to see the logged results.

## Reflection & Learnings
The primary goal of this task was practicing different function syntaxes while processing array data.
