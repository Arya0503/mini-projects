# Task: Dynamic Laundry Booking Portal

## Project Overview
This project simulates a dynamic service booking application. It features a right-side interface for cycling through available services and a left-side interface that actively tracks the user's cart state and calculates a running total before form submission.

## How to Run
1. Unzip the project folder.
2. Open `index.html` in your browser.
3. Click "Add Item" or "Skip Item" to cycle through the available services.
4. Fill out the booking form and click "Book now" to trigger the success state.

## Personal Reflection
This task was a fantastic exercise in managing application state across different UI components. Because I had to keep track of a running total and a list of selected items, it felt very similar to managing in-memory backend logic, just applied directly to the DOM.
