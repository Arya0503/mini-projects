# OmniFood Responsive Landing Page

## Execution Instructions

1. Open the `index.html` file in any modern web browser.
2. The UI is completely built with HTML and CSS. No local server or dependencies are required.

## Responsive Behavior

- **Desktop (≥1200px)**: Grid layout matches standard specs.
- **Tablet (≤834px)**: Sections stack nicely, cards convert into a 2-column layout.
- **Mobile (≤550px)**: Single column layout applied.
