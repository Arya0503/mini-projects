# Greenwood Library Website

## Overview

A minimal, modern, editorial-style landing page designed to showcase the Greenwood Public Library's spaces, sections, events, and membership plans. Built entirely with HTML and the Tailwind CSS CDN.

## How to Run

1. Open the `index.html` file in any modern web browser.
2. The UI is completely built with HTML and native Tailwind CSS utility classes. No local server, build process, or external CSS files are required.

## Features & Implementation

- **Responsive Layouts**: Designed using Tailwind grids and flexbox to scale flawlessly from mobile to desktop.
