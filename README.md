# Projects - AI Hero Section

## Overview

This project is a modern, responsive hero section for an AI-powered connected workspace.

## Key Features

- **Sticky Navigation:** A top navbar with a blur backdrop that remains visible while scrolling.
- **Gradient Hero Section:** A smooth light orange to white gradient background for a modern aesthetic.
- **Precise Positioning:** Extensive use of relative and absolute positioning to align Call-to-Action buttons and float informational cards (Tasks, Project Status, Team Activity) over the main dashboard preview.
- **Floating UI Elements:** Z-index manipulation and drop shadows to create depth for overlapping cards.
- **Fixed Chat Widget:** A persistent chat button anchored to the bottom-right corner of the screen.

## How to Run

1. Extract the project folder.
2. Open the `index.html` file in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No local server, build tools, or node modules are required since Tailwind CSS is imported via CDN.
